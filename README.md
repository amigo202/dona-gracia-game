# מסע בעקבות דונה גרציה · לומדה משחקית

גרסה משחקית של המסע, מבוססת על הקוד, הטקסטים והעיצוב המאושרים מ־16.11.2026.

## מה יש במשחק

- מסך פתיחה עם שם השחקנית (לתעודה) ומפת מסע מונפשת.
- מפת מסע: התחנות נפתחות לפי הסדר, אחרי השלמת המשימה בתחנה הקודמת. ההתקדמות נשמרת ב־localStorage במכשיר.
- בכל תחנה ארבעה שלבים: סיפור (עם "הקשיבו" ו"מושג לדרך"), דילמה "את דונה גרציה ב…, מה תעשי?" עם משוב, משימה משחקית, ותג.
- המשימות: ליסבון: נכון או לא נכון · אנטוורפן: חידון מהיר · ונציה: מצאו את ההמצאה בטקסט שכתב AI · פררה: ציר זמן (גרירה או חצים) · איסטנבול: משחק זיכרון של מושגים · טבריה: מיון לרצון, מעשה ותוצאה.
- ניקוד: עד 100 לתחנה (30 דילמה + 70 משימה), כוכבים ותג לכל תחנה, עד 600 בסך הכול.
- תעודת מסע עם שם, ניקוד ותגים, מותאמת להדפסה או לשמירה כ־PDF (A4 לרוחב).
- מקום לתוצרי חקר של תלמידות בכל תחנה: `src/game/research.ts`.
- עמוד מקורות וקרדיטים בתוך המשחק.

## הרצה ובנייה

```sh
npm ci
npm run dev      # פיתוח
npm run build    # בנייה לתיקיית dist
npm run preview  # צפייה בתוצר
```

הניווט בנוי על # (למשל `#/lisbon`, `#/map`, `#/certificate`) ו־base יחסי, ולכן אפשר לארח את `dist` בכל שירות סטטי ובכל תיקייה, בלי הגדרות הפניה.

## קבצים מרכזיים

- `src/App.tsx`: המסכים (פתיחה, מפה, תחנה, תעודה, מקורות).
- `src/game/content.ts`: הדילמות והמשימות של כל תחנה.
- `src/game/MiniGames.tsx`: שישה סוגי משחקונים.
- `src/game/JourneyMap.tsx`: מפת המסע המונפשת.
- `src/game/store.ts`: שמירת התקדמות, ניווט וקריינות.
- `src/game/research.ts`: תוצרי החקר של התלמידות (ריק כרגע).
- `src/game.css`: העיצוב (על בסיס הפלטה והרכיבים המאושרים).
- `src/screens.json`: הטקסטים המקוריים, ללא שינוי.
- `src/map-base.svg`: המפה המאושרת בלי קווי המסלול (המסלול מצויר ומונפש בקוד). `src/map.svg` ו־`src/style.css` נשמרו כמקור.

## גבולות הגרסה

אין שרת, חשבונות או מפתחות API. ההתקדמות נשמרת רק בדפדפן שבו משחקים. הקריינות היא קול הדגמה של הדפדפן; איכותה תלויה בקול העברי שמותקן במכשיר, ובמכשירים בלי קול עברי היא עלולה לא להישמע (מוצגת הודעה). טבריה היא תחנת חזון ולא מקום שבו דונה גרציה חיה. הכיתוב "גרסת עבודה פרטית" הוא תווית בלבד, בלי בקרת גישה.

## סטודיו הכיתה (גרסה 3, 17.11.2026)
בכל תחנה, בשלב הסיפור, יש «סטודיו הכיתה»: כרטיס «החוקרות שלנו» (שמות פרטיים, עובדה, מקור, תמונה לא חובה) והקלטת קריינות עם טלפרומפטר (טקסט קריינות או «מכתב מדונה גרציה», כתיבה יצירתית). העמוד `#/studio` מרכז ייצוא וייבוא.
- **מקומי**: כרטיסים ב־localStorage (`dona-gracia-contrib-v1`), הקלטות ב־IndexedDB (`dona-gracia-audio`). נשמרים רק במכשיר עד ייצוא.
- **אפייה לגרסה הציבורית** (בלי בנייה מחדש, הקובץ נטען בזמן ריצה):
  - `public/contributions.json`: `contributions` (אותו מבנה כמו בקובץ הייצוא), `credits` (שמות נוספים), `media.audio` / `media.video` (מפה תחנה ← נתיב יחסי).
  - קבצים: `public/audio/<תחנה>.(m4a|mp3|webm)`, `public/student-video/<תחנה>.mp4`. אם אין מפתח `media` ב־json, המשחק בודק את הנתיבים האלה בעצמו.
- סדר הקריינות: הקלטה במכשיר ← הקלטה אפויה ← קול הדגמה של הדפדפן.
- טקסטי הקריינות: `src/game/narration.ts` ו־`NARRATION.md`.
